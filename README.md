# WHY NOT Boutique E-commerce

## Description
Site vitrine et boutique e-commerce premium de la marque WHY NOT, créé en HTML, CSS et JavaScript. Il comprend :

- collection vêtements (t-shirts, shorts, pulls, casquettes)
- accessoires premium (montres, ceintures, lunettes, bijoux, protection téléphone)
- panier d'achat dynamique
- paiement sécurisé
- livraison partout au Sénégal
- suivi de commande
- promotions et newsletter
- support client chat

## Fichiers du projet

- index.html
- styles.css
- script.js

## Installation

1. Téléchargez ou ouvrez le dossier du projet.
2. Ouvrez le fichier index.html dans votre navigateur pour visualiser le site.
3. Pour un environnement local plus réaliste, vous pouvez aussi lancer un petit serveur local :

```bash
cd "c:\Users\user\Downloads\projet 1"
python -m http.server 8000
```

Ensuite ouvrez :

```text
http://localhost:8000
```

## Personnalisation

- Pour modifier les couleurs et l’identité visuelle : voir les variables CSS dans styles.css.
- Pour ajouter des produits : modifier le tableau productData dans script.js.
- Pour ajouter des accessoires : modifier le tableau accessoryData dans script.js.

## Déploiement

Pour mettre le site en ligne :

1. Hébergez les fichiers sur un service statique (GitHub Pages, Netlify, Vercel, Hostinger, etc.).
2. Vérifiez la compatibilité responsive sur mobile et ordinateur.
3. Ajoutez ensuite une backend Node.js + base de données pour le paiement réel, les comptes clients et le suivi complet des commandes.

## Remarques importantes

- Le site actuel est une version front-end fonctionnelle et moderne.
- Les éléments de paiement et les livraisons sont simulés côté interface.
- Pour un projet de production complet, il faudra intégrer une vraie API de paiement et un système backend sécurisé.
